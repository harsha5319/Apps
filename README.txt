# DAYFORGE — Daily Routine, Food & AI Cybersecurity Study Tracker

## Files
- `index.html` — app structure
- `style.css` — responsive styling
- `script.js` — tasks, dashboards, local save, backup import/export

## Run it
1. Extract the ZIP file to a folder.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. Use the left navigation to open Dashboard, Daily routine, Study tracker or Cyber roadmap.
4. Choose the tracking date at the top. Mark routine items, study tasks and roadmap items as you complete them.

No installation, account, server, database or API key is needed.

## Local storage and backups
- Progress is stored in this browser using `localStorage`; it does not sync to other devices.
- Use **Export backup (JSON)** regularly to save a copy of your progress.
- Use **Import backup (JSON)** to restore a backup.
- Clearing browser site data can erase local progress, so export backups if the information matters to you.
- The app uses an optional Google Fonts import for typography; if you are offline, it falls back to system fonts.

## Included study tasks
All seven subjects (OS, Java, AIML, Maths, Frontend, IoT and Cybersecurity) have H.A. 1–6, ALM 1–6 and Workbook Weeks 1–20. Maths also has Tutorials 1–20. The cybersecurity roadmap includes five phases with individual checkboxes.

## Notes
This is a personal tracker, not a medical or nutrition prescription. Adjust meals and exercise to your own needs. Only use cybersecurity tools on systems you own or are explicitly authorized to test.
